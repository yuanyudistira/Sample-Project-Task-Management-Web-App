# Secure Todo App Starter

Professional todo app template untuk belajar GitHub Security, 
Docker, dan CI/CD Pipeline.

## Branches

- `main` - Production-ready, fully secured
- `modul-1-vulnerable` - **START HERE** for course
- `modul-2-secured` - Solution reference

## Quick Start (for Students)

\`\`\`bash
git clone https://github.com/infosecguru/secure-todo-app-starter
git checkout modul-1-vulnerable
npm install
npm run dev
\`\`\`
